# TempoBrowser beta-1

TempoBrowser 是基于 Chromium / Electron 的 Windows 中文桌面浏览器。beta-1 将媒体播放、网页动画和页面计时合并到同一个加速开关与倍率设置，可用于日常浏览、媒体调速及本地网页计时与数据上报实验。

## 本版内容

- 统一控制已支持的 HTML5 音视频、页面时钟、定时器和动画。
- 提供 ×1、×2、×3、×5、×10、×20 六挡，显示实际时钟与媒体倍率反馈。
- 每个标签页独立保存配置，刷新与跳转后继续生效。
- 关闭开关保留所选倍率，恢复原速会回到 ×1。
- 移除启用网页时间加速时的实验预警弹窗。
- 保留多标签、搜索、导航、书签、历史、下载、持久登录、数据清理及浅深主题。

## 实际验证

已运行六挡约 10 秒测量、35 项统一加速及基础界面检查、15 轮前后端计时回归和 6 轮媒体与上报同页测试。

×2 下，现实约 10 秒，页面和请求累计约 20 秒。后台采用前端累计值时记录并采用约 20 秒，采用自身时钟时最终采用约 10 秒。运行中 ×1→×2→×1 的累计值保持连续。

## 使用

下载 `TempoBrowser-beta-1-win-x64.zip`，完整解压后运行 `TempoBrowser.exe`。用户无需额外安装 Node.js、Chrome 或 WebView2。程序数据与下载分别保存在程序旁的 `user-data` 和 `Downloads`。

## 已知限制

Chromium 拒绝媒体 ×20，界面会显示部分生效和实际值。页面时钟与已支持动画仍可达到约 ×20。高倍率有丢帧、缓冲和声音异常风险。

Worker、DRM、自定义播放器、服务器时间和网络存在机制边界。其他 Windows 系统构建、真实第三方业务、隐藏页面、断网重试和高倍速音质均未验证。程序尚未代码签名。

附件包含便携程序、源码和 SHA256 校验文件。完整范围见仓库 README 和验证报告。
